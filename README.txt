TRABALHO DE POO — FUNCIONÁRIOS, PJ E PROFESSOR
================================================

ARQUIVOS
- Funcionario.java: classe base, cálculos CLT, INSS, IRRF, FGTS e líquido.
- FuncionarioPJ.java: herança e cálculo por hora com DAS.
- Professor.java: sobrescrita do bruto para professor CLT.
- Main.java: criação dos cinco objetos, apresentação e testes.
- Ficha_de_Testes_e_Reflexao.md: resultados, ficha e respostas da reflexão.

COMO ABRIR E EXECUTAR NO VISUAL STUDIO CODE
1. Extraia o arquivo ZIP para uma pasta.
2. Abra o Visual Studio Code.
3. Vá em File > Open Folder e selecione a pasta Trabalho_POO_Funcionarios.
4. Certifique-se de ter o JDK instalado e configurado.
5. Abra o terminal integrado (Terminal > New Terminal).
6. Execute:
   javac *.java
   java Main

Não coloque os arquivos em pastas diferentes: os quatro .java devem ficar juntos.
O programa usa apenas recursos padrão do Java, sem bibliotecas externas.

OBSERVAÇÃO
Os valores seguem as regras didáticas do enunciado, não uma calculadora tributária
para uso real. O regime é definido no construtor e não pode ser alterado.
